# Что можно удалить из СКД закупок

Актуальная рабочая выдача отчета `MON_МониторЗакупокЭксперимент` оставляет наружу слои `КонтрольНормы`, `КонтрольКонтура` и диагностический слой `СверкаExcelНормы`. Виджет монитора больше не формирует этот отчет в фоне: он считает компактные итоги по той же методологии прямо в модуле обработки, а СКД используется только при открытии детализации по гиперссылке.

Ниже список полей, которые можно удалить из ручного списка полей и ресурсов СКД, если они нигде не используются в твоих вариантах отчета. В модуле объекта они могут оставаться как внутренние расчетные колонки.
