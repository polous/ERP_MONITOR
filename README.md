# ERP_MONITOR

Монитор бизнес-метрик для директора в 1С ERP.

Проект ведется как отдельное расширение `ERP_MONITOR`. Основной экран - внутренняя обработка `MON_МониторРуководителя` с виджетами по складам, продажам и закупкам. Из-за работы 1С через удаленный стол мы не редактируем объекты расширения напрямую из репозитория: код модулей, запросы СКД и диагностические материалы хранятся в текстовых файлах, затем вручную переносятся в конфигуратор 1С.

Главная рабочая памятка: [docs/PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md).

## Ключевые файлы

- `МОДУЛЬ_ОБРАБОТКИ.txt` - модуль формы/обработки `MON_МониторРуководителя`.
- `МОДУЛЬ_ОБЪЕКТА_ОТЧЕТА_ПРОДАЖ.txt` - модуль объекта отчета `MON_МониторПродаж`.
- `СКД.txt` - сохраненные фрагменты/запросы СКД, сейчас в основном по закупкам и остаткам.
- `ЛОГ.txt` - диагностический вывод расчетов закупочного виджета.
- `*.xls`, `*.xlsx` - исходные/контрольные таблицы для сверок.

## Рабочее правило

Любое изменение для 1С сначала делаем в соответствующем `.txt` файле репозитория. После проверки пользователь вручную переносит фрагмент в расширение 1С через удаленный рабочий стол.
